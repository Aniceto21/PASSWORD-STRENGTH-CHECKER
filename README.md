🔐 PASSWORD-STRENGTH-CHECKER

A responsive and interactive Password Strength Checker built using HTML, CSS, and JavaScript.
This project evaluates password strength in real time based on standard security parameters and provides dynamic visual feedback to enhance user awareness of password security best practices.

📌 Project Overview
The Password Strength Checker is a front-end web application designed to:
Analyze password complexity instantly
Provide visual strength indicators
Encourage strong password creation
Improve basic client-side security validation
It applies common password evaluation criteria such as:
Minimum length requirement
Uppercase characters
Lowercase characters
Numeric digits
Special characters

🚀 Features
✅ Real-time strength evaluation
✅ Dynamic color-coded strength indicator (Weak / Medium / Strong)
✅ Responsive UI design
✅ Clean and minimal interface
✅ Client-side validation logic
✅ No external libraries required

🛠️ Tech Stack
Technology	Purpose
HTML5	Structure and layout
CSS3	Styling and responsiveness
JavaScript (ES6)	Password validation logic and DOM manipulation

🧠 Strength Evaluation Logic
The password is evaluated based on:
Length (recommended ≥ 8 characters)
Presence of uppercase letters
Presence of lowercase letters
Inclusion of numeric characters
Inclusion of special characters

Strength categories:

🔴 Weak – Poor security, easily guessable
🟡 Medium – Acceptable but improvable
🟢 Strong – Secure and complex
